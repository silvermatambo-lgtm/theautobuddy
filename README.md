# The Autobuddy — Ultra Max 5 Vercel App

A Vite + React + TypeScript PWA prototype based on the supplied WebDevPro Ultra Max 5 template.

## Included
- Public marketing pages
- Services and 4-step buying journey
- Trade-only catalogue UI with filters, stock status, offer modal, WhatsApp and save buttons
- Vehicle details upload form
- Up to 20 image upload preview
- Inspection report page
- Dealer login demo
- Admin/dealer dashboard prototype
- Interactive WhatsApp assistant
- PWA manifest and Vercel SPA routing
- Responsive mobile bottom navigation

## Important production note
Dealer authentication, persistent inventory, real offer management, secure file uploads, PDF storage, email delivery and admin permissions are currently front-end demonstrations. Connect Supabase/Firebase/another backend before handling real customer or dealer data.

## Vercel
Framework: Vite
Build command: npm run build
Output: dist
